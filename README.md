# TSUE Digital Economy Faculty Portal

Официальный интерактивный портал факультета «Цифровая экономика» Ташкентского государственного экономического университета (TSUE).

## Особенности
- **Интерактивная навигация и презентация факультета**: кафедры, образовательные программы (бакалавриат / магистратура), лаборатории.
- **Инкубатор стартапов и R&D лаборатории**: FinTech Lab, Big Data & Analytics Hub, AI Research Center.
- **Мультиязычная поддержка**: интерфейс и локализация данных (UZ / RU).
- **Карьерные треки и партнеры**: ведущие банки, IT-компании, финтех и госорганы.
- **Актуальные новости и события**: живая интеграция и карточки событий.

## Стек технологий
- **Frontend**: Чистый HTML5, модульный JavaScript (ES6+), Vanilla CSS3 с адаптивным современным дизайном (Glassmorphism, Dark/Accent палитра).
- **Данные**: Структурированные локализованные датасеты (`faculty_curated.json`, `faculty_data_uz.json`, `faculty_data_ru.json`, `live_news.json`).
- **Скрипты обработки**: Node.js пайплайн парсинга и курации данных (`prepare_data.js`).

## Локальный запуск
Для запуска достаточно любого локального веб-сервера:
```bash
# С помощью Python
python3 -m http.server 8000

# Или с помощью npx serve
npx serve .
```
Откройте в браузере: `http://localhost:8000`
