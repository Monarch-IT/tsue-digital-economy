# Global Rules

- Писать без комментариев в коде.
- Писать без пробелов там, где это допустимо (компактный и лаконичный стиль).
- Мыслить нестандартно и находить альтернативные, креативные архитектурные решения.
- Писать и модифицировать весь код исключительно через нативные инструменты Antigravity IDE, не через cmd/терминал.
- Никаких эмодзи в интерфейсе сайта — только строгий, официальный академический стиль ТГЭУ.
- В качестве бэкенда и realtime-синхронизации использовать Supabase.
